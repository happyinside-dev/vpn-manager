OpenWRT и два режима маршрутизации

Telegram: Мои ссылки → устройство → режим → Source/Import/QR.
Новое устройство: OpenWRT (/openwrt).
Режимы: VPN, кроме РФ / Только заблокированные.

Обновление существующего VPS из этого каталога:
  sudo ./upgrade-telegram-only.sh

Комплект содержит пересобранный vpn-manager для Linux amd64.
Обновление на VPS необходимо выполнить отдельно; изменение файлов в репозитории
не обновляет уже установленный сервер.

Подробности, зависимости и настройка DNS роутера: ROUTING.md.

proxy-manager v2.4.2 subscription bundle

Fixes Hysteria2 external SNI mode.

When HY_INSECURE=1 the generated /etc/hysteria/config.yaml now contains:

  tls:
    cert: /etc/hysteria/server.crt
    key: /etc/hysteria/server.key
    sniGuard: disable

This is generated by write_hysteria(), so the setting survives account add,
rotate, enable, disable, delete, apply, and reinstall/regeneration.

Recommended update for the current server:

  sudo XRAY_SNI="vpn.example.com" \
       HY_SNI="bing.com" \
       HY_INSECURE=1 \
       ./install-with-subscriptions.sh ./proxy-manager-v2.2.sh -S

The -S flag preserves current VPN credentials.

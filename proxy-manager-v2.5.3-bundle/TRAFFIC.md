# Трафик в Telegram

Администратор: **👥 Пользователи → имя пользователя → 📊 Статистика**
показывает его трафик за всё время и последние 7 дней. Кнопки под отчётом
позволяют обновить данные, вернуться к пользователю, выбрать другого или
открыть главное меню.

Постоянные кнопки навигации отображаются под полем ввода: **👥 Пользователи**,
**📊 Статистика**, **🏠 Меню** и другие действия. Они появляются и при первом
обращении после обновления; нажатие навигации отменяет ввод имени нового профиля.

Администратор: кнопка **📊 Статистика** или `/traffic` показывает все профили
(сумма отправленных и полученных байтов Xray и Hysteria).
`/traffic NAME` и кнопка **📊 Статистика** в карточке пользователя показывают
статистику выбранного профиля за всё время учёта и последние 7 × 24 часа.
Обычный пользователь видит только свой профиль: `/traffic` или **📊 Моя статистика**.
Статистика привязана к имени VPN-профиля, а не к Telegram ID.

Сбор выполняется ботом раз в минуту. Данные сохраняются атомарно в
`/etc/vpn-manager/traffic.json` с правами 0600 и переживают перезапуск бота.
Не удаляйте этот файл при обновлении; включите его в резервные копии.
Первое успешное чтение каждого источника устанавливает начальный счётчик:
трафик до начала учёта не добавляется, поскольку его даты неизвестны.
После этого общая сумма хранится бессрочно, а поминутные приращения — 7 дней.
Граница недели имеет точность интервала опроса. При длительной остановке бота
накопленное приращение относится ко времени следующего успешного опроса.

Бот не обнуляет счётчики демонов. Перезапуск определяется по systemd InvocationID
или уменьшению счётчика. Трафик между последним опросом и сбросом демона может
потеряться; это периодический учёт, а не биллинговая система.
Если API недоступен, бот показывает сохранённые значения с предупреждением
и временем последнего успешного чтения каждого источника.

## Обновление существующей установки из этого комплекта

Перенесите обновлённый комплект на сервер и выполните:

```sh
cd proxy-manager-v2.5.3-bundle
sudo bash ./upgrade-traffic.sh
```

Скрипт сохраняет резервные копии, включает StatsService Xray на
`127.0.0.1:10085` и Traffic Stats Hysteria на `127.0.0.1:10086`, обновляет
установленный core-скрипт (чтобы управление аккаунтами сохраняло настройки
сбора), бинарник и Telegram-бот. Требуются python3 и зависимости существующего
установщика. **Xray и Hysteria перезапустятся, текущие подключения прервутся.**
UUID, пароли и subscription tokens сохраняются. При нестандартных конфигурациях
настройте API вручную. Один `upgrade-telegram-only.sh` не включает API демонов.
Новая установка через `install-with-subscriptions.sh` включает их автоматически.

## Настройка

Старый `telegram.json` работает без дополнительных полей. При необходимости
добавьте в него объект (все поля необязательные):

```json
"traffic": {
  "file": "/etc/vpn-manager/traffic.json",
  "xray_binary": "xray",
  "xray_server": "127.0.0.1:10085",
  "hysteria_url": "http://127.0.0.1:10086",
  "hysteria_secret": ""
}
```

API статистики должны слушать loopback. Публичные порты открывать не нужно.
Если у существующего Hysteria API задан `secret`, укажите его в
`hysteria_secret`. Сбор работает, пока запущен `vpn-manager-telegram`.
При удалении и повторном создании профиля с тем же именем его история продолжается.

Сборка бинарника комплекта из исходников (Linux amd64, Go 1.23+):

```sh
cd src
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o ../vpn-manager ./cmd/vpn-manager
```

Форматы API: [Xray Stats](https://xtls.github.io/config/stats.html),
[Hysteria Traffic Stats](https://v2.hysteria.network/docs/advanced/Traffic-Stats-API/).
